# General FAQ

## 1. How do I track my order?

Tracking is available in the customer's account order history, or via the tracking link emailed on dispatch. See
the Shipping & Delivery Policy for expected timelines.

## 2. How do I return an item?

Start a return from the account order history within 30 days of delivery. See the Returns & Refunds Policy for
what is and isn't eligible.

## 3. What if my item arrives damaged?

Report it within 7 days of delivery with photos attached. See the Damaged & Defective Items Policy - this is a
faster and separate process from a standard return.

## 4. How do I redeem loyalty points?

Points can be applied at checkout once logged into a loyalty account. See the Loyalty & Rewards Program for
redemption limits.

## 5. How is my personal information used?

Only for order fulfilment, support, and account/loyalty management, unless separately opted in to marketing. See
the POPIA Data Privacy Notice for full detail.

## 6. Can I change my delivery address after ordering?

An address can be changed only before dispatch, by contacting support with the order number - once dispatched,
the delivery address cannot be changed and the order should instead be tracked and, if needed, redirected via the
courier's own service where available.
