# Order Cancellation Policy

## 1. Cancellation before dispatch

An order can be cancelled free of charge at any time before it is dispatched. Once dispatched, it can no longer be
cancelled - the customer must wait for delivery and then use the standard returns process instead.

## 2. How to request a cancellation

Cancellation requests must include the order number and are actioned as soon as the warehouse confirms the order
has not yet been picked and packed. If packing has already started, the cancellation cannot be guaranteed even if
the order has not technically been marked "dispatched" yet.

## 3. Refund timing for cancellations

A cancelled order is refunded in full within 3 business days, faster than the standard 5-7 business day return
refund timeline, since no physical item needs to be received and inspected.

## 4. Cancellations due to stock unavailability

If Fynbos Retail cancels an order because an item is out of stock after payment was taken, the customer is
notified immediately and refunded in full within 3 business days, with no action required from the customer.

## 5. Partial cancellations on multi-item orders

A single item can be cancelled from a multi-item order before dispatch without affecting the rest of the order,
provided the remaining items have not yet been packed together with the cancelled item.
